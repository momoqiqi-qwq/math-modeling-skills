# 工具隐性约束 · `tools/docx` 的实际判定行为

> `paper_format.py` 有一批**规范里没写**的判定，违反即**阻断保存**，且报错措辞不直观。
> **定位方式：函数名 + 正则/判据原文 + 报错串。行号只作脚注**——工具一升级，行号全部指向别处，比没有行号更误导（这是 2026-11-14 实跑后改的结构，原先按行号写）。
> 脚注里的行号对应 `2026-11 实测版本`：`SKILL_ROOT/tools/docx/scripts/paper_format.py`。

## 一、五条最致命的

### C1 正文段落不能以「图N / 表N」开头
- 判据（`validate_document` 内）：`caption_pattern = re.compile(rf"^\s*{kind}\s*(\d+)(?!\d)")`，**段首即匹配**即登记为题注；不匹配的段里出现「图N/表N」才算正文引用。
- 报错：`ValueError('论文结构校验失败: 图1 已插入但未在正文引用')`；编号不连续另有 `表编号不完整，缺少题注: [1]` / `题注没有对应对象或编号跳跃: [1]`。
- 规避：正文写「**由图1可见**」「**见表2**」；题注段单独写、以「图 1」「表 1」开头。

### C2 三线表不生成题注
- `three_line_table(doc, rows)` 只画表；`figure_caption(doc, text)` 只写一段文字。二者都不算「题注已存在」。
- 报错：`表编号不完整，缺少题注: [1]`。
- 计数口径（别数题注）：图 = `.//a:blip`、表 = `len(doc.tables)`、公式 = `.//m:oMath`。**图必须真的以图片插入**，SVG 直接塞进去不算。

### C3 内部流程词是硬过滤，不是提示
- 判据：`_internal_process_issues`，四条正则 —— `门禁|阶段门禁|门禁状态|独立验收`；`\bsubagent\b|子代理`；`质检简报|证据大纲|复现清单|质检回执|门禁回执`；`质检|回执`。
- 机制：这些 issue **不带「预警：」前缀**，而 `save_document` 只放行以「预警：」开头的条目 ⇒ 命中即抛
  `ValueError('论文结构校验失败: 疑似内部流程术语残留（…）：…')`。
- **最坑**：`质检` 是「质量检验」的**子串**。「质量检验」「来料质检」「质检工位」在工业题里照样命中。只能换词（「检验工序」「合格判定」「检验环节」），**且这是语义让步，必须在 deviations 留痕**——将来工具修好要把原词换回来。
- 「命中后逐条判断」在 `save_document` 层做不到：那是硬过滤。

### C4 `heading1` 强制分页，直接吃页数
- `heading1()` 内设 `paragraph_format.page_break_before = True`。
- 影响：每个一级标题另起一页。11 个一级标题（摘要 + 9 章 + 附录）= 至少 11 次强制分页，30 页上限下正文可用页数被显著压缩。
- 规避：**不为省页合并章节**；页数预算按「章数 × 分页」重算，并在 deviations 记明。

### C5 未知 LaTeX 命令/环境硬报错，不静默降级
- 报错串：`ValueError: 不支持的 LaTeX 环境: array`、`ValueError: 不支持的 LaTeX 命令: \Rightarrow`、`ValueError: LaTeX 分组缺少右花括号 '}'`（`equations.py` 转换器）。
- 已验白名单：`cases / frac / sqrt / sum / left( right) / mathbf / mathbb / bar / overline / partial / text / tag / times / cdot / le / ge / neq / approx / in / forall / exists / to / Delta / lambda / min / max / dots`
- 写法：分段函数用 `cases`；「蕴含/推出」用中文「因此」「可得」，不用 `\Rightarrow`；矩阵改写成分量式。

## 二、另外五条

### C6 Markdown 残留一律判错（`_markdown_residual_issues`）
九类：代码围栏、`**粗体**`、行内反引号、行首 `#`、行首 `- + * ` 列表符、`$$…$$`、行内 `$…$`、Markdown 表格分隔行、Markdown 表格行。最易踩三处：
1. 符号写成 `$x_A$`（术语表的源写法就是这种）→ 命中「行内公式定界符」抛错。符号列要转 OMML 或 Word 真下标。
2. 附录贴代码用围栏 → 抛错，改用等宽字体段落。
3. 用「- 」列假设 → 抛错，改用「（1）（2）」或中文分号。

### C7 参考文献章标题必须精确
- 判据：`p.text.strip().lower() in {"参考文献", "references"}`。
- 实测：`参考文献`✓、`References`✓、`参考资料`✗（`未找到参考文献章节`）、`参考 文献`✗。

### C8 参考文献双向对应，一条都不能多
- 判据：正文侧抓 `[n]`（支持 `[1,3-5]` 区间），文末抓 `^\[(\d+)\]` 开头的段落，两集合**必须完全相等**。
- 报错：`参考文献 [3] 未在正文引用` / `正文引用 [3] 未出现在参考文献表`。

### C9 篇幅/图数/式数/表数/页数只是预警，但 CLI exit 1
- 机制：这五类 issue 以「预警：」开头，`save_document` 时被过滤 ⇒ **不阻断保存**；而 `passed = not issues` ⇒ CLI `exit 1`。
- 准确口径：**能存、门禁红**。deviations 要点名是哪几条预警，别只写「exit 1」。

### C10 模板是空壳
- `new_document(template_path=tpl, preserve_template_content=False)` 删掉除 `w:sectPr` 外全部 body 子元素；模板里**没有 Heading 样式**，全是 Normal。
- 保留模板的意义只剩页面设置（A4 + 页边距 2.54/2.54/3.17/3.17 + 单节）。

## 三、不在工具里、但同样挡事的四条

### C11 页数只能实测
`--rendered-pages` 是**自报值**，工具不核。唯一可信：Word COM `ComputeStatistics(2)`。20 页是质量目标（`target_pages`），30 页是硬上限（`official_max_pages`，超过直接 `passed=False`）。当届规则不同以官方文件为准，并在 deviations 记明依据。

### C12 符号呈现：真下标优先，OMML 只在公式里
正文与表内的 `λ_D` 若以纯文本下划线呈现，评委一眼看出排版不统一。改法是 Word **真下标**（`run.font.subscript = True`），不是转 OMML：真下标 0 字 0 页，OMML 要重排可能涨页。
**副作用**：转真下标后 `docx` 纯文本抽取得到 `λD`，与源 CSV 不再逐字相同。可回溯性判据要改成「**逐格语义对应 + 行可定位**」，不能拿「逐字相同」当唯一证据。

### C13 段号：交付与回执都必须声明口径
三种数法会给出三个数：**0-based 段序**、**1-based 段序**、**`:0094` 风格行号**。实测同一处改动，作者报 `p95`、质检员报 `:0094`，看起来差一位，其实是同一段。
规则：① 报段号必须写「0-based」还是「1-based」；② 新增/删除段落会使其后段号整体位移，**交付必须自带对齐规则**（如「新件 p0–p178 同号，p179 新增，p180 起 ↔ 旧件 p179 起」）；③ 比对要说明**按文本比还是按 run 比**——真下标化会让「文字未变」的段落 run 结构改变（实测：文本口径 17 段变 / run 口径 21 段变）。

### C14 图宽是「换页数」的手段，不是审美
超出官方页数上限时，正确处理顺序是：**先压图宽 → 再删冗余 → 最后才动论点/图数**。实测 10.4 cm → 8.8 cm 把 31 页压回 30 页，正文一字未删。压缩决定要进 deviations，并写「若上限放宽，第一步改回图宽」。
