# M1 要跑几轮、要花多少（实测）

> 本文件原在 `四方路由.md` §10。移到这里的原因：它讲的全是 math-modeling 自己的质检节奏，不需要任何外部 skill 在场。2026-11-14 端到端验证后搬回。

## 1. 同一份报告连跑六轮 M1

2024 CUMCM C 题（农作物种植策略，附件 1–3 全缺）建模报告的实测轨迹：P0 走 **4 → 1 → 0 → 0 → 0 → 0**，P1 走 **6 → 6 → 3 → 1 → 1 → 0**，第六轮 PASS。

| 轮 | 探照灯照到哪 | 这轮抓到的东西长什么样 |
|---|---|---|
| 1 | 结构 | 求和指标悬空（`Σc_{j,t}x_{i,j,s,t}` 里 i,s,t 没定义）、把已知年份当决策变量 |
| 2 | 端点/补集 | 模式互斥只做了一半，θ=0 时伪解能通过 |
| 3 | 方向 | 改成求和式后**过紧**，把「一季水稻」钉到具体季次 |
| 4 | 字面 | 「2023 年销售价格的 50%」抄成当年价 `p_{j,t}` |
| 5 | 随机结构 | 等式两端挂 `ω`、右端无随机项，成本零方差 |
| 6 | PASS | 剩 4 条 P2、4 条 BLOCKED（附件缺失，等人工） |

## 2. 五条要记住的

1. **M1 不是收敛过程，是逐层下潜。** 四轮的抄错年份、五轮的成本零方差，都是第一版就躺在那里、前几轮没人查到的老账。所以「改得多好」不决定轮数，「查到多深」决定。别问「三轮够不够」，问「探照灯照到底了吗」——而底在哪，事先不知道。
2. **宣称完备处就是漏洞处。** 凡是自己写「已排除伪解」「已覆盖全部情形」「模式互斥」的地方，逐字验补集；三轮三次都栽在这里。已落成 [质检清单.md](roles/建模手/references/质检清单.md) 第 12 条。
3. **过松算错，过紧也算少。** 约束比题面更紧会静默丢解、而且不报错，比过松更危险。超出题面文字的收紧，要么放开，要么显式登记成建模约定。已落成第 13 条。
4. **P1 与 P2 的分界是「能否骗过验证」，不是「看着多严重」。** 能通过全部 V1–V6 而系统性出错的，判 P1；进不了可行域、失效时会看见 NaN 的，判 P2。
5. **加随机性也是一种编造。** 题面只给「5% 左右」的均值、不给离散幅度，补一个 `ψ∼U(−δ,δ)` 等于替题面发明 δ。正确做法是声明「成本取点估计」，把口径摊在明面上。同理，把作物级一次抽样强行改成逐年 iid，是替题面发明「年度独立」这个更强约定。

## 3. 轮数的可操作闸门（E2E 实测得出）

2026-11-14 用「工厂排产」两变量 LP 跑 M1：**1 轮 PASS**，耗时 2.6 分钟，5 份文件 242 行；同一套流程在 C 题要 6 轮。

$$	ext{轮数} propto 	ext{「质检者自己算不出、必须外部证据才能判真假的断言数」} 	imes 	ext{附件缺失度}$$

**不正比于字数、页数、公式数。** C 题六轮的真驱动是「附件 1–3 全缺（B1–B4 恒 BLOCKED）+ 9 条不可复算断言（弹性、相关性、文献强度）」。

由此得两条闸门：

- **首轮 P1 = 0 且 BLOCKED = 0 ⇒ 第二轮没有新判定依据 ⇒ 该轮即应 PASS**，不要为了「跑够几轮」再跑一轮。
- **只要还有 BLOCKED，轮数下限由附件何时到位决定**，不由 M1 决定。此时报告应出「PASS（附 BLOCKED 清单）」而不是等。

## 4. PASS 的边界必须写进回执

M1 第六轮的 PASS 只承诺：前置合同八项逐项有答、9 节齐、16 条清单 15 PASS、参数化写法正确、符号层无自相矛盾（17 式全局符号全命中且一符一义）、验证项可执行、文献可解析。

**不承诺**：任何数值结论、附件缺失下的可行域规模、符号方向、文献论断强度、自定阈值的实证性（±5%、gap 0.5/2%、Spearman 0.8/0.9、Γ∈{0,2,5,10}、|Ω|∈{100,200,400}）、以及「成本已随机化」。

**PASS 不是一个瞬间，是一段带边界的句子。** 回执里不写边界，等于把不确定性偷偷转给编程手。
