# 获奖论文拆解套路 · 可执行清单

> 用途：stage 1 选题、stage 2 拆问、stage 3 选型时，把"获奖论文为什么看起来强"翻译成能当场勾的条目。
>
> 来源与边界：结构提炼自 [y3519712124-ui/math-modeling-contest-route-selection](https://github.com/y3519712124-ui/math-modeling-contest-route-selection)（MIT）的四份参考文本（子问拆解、路线模式库、反驳式选型、工程可行性）与题型分类。以下均为中文重写，不保留原文句式；也不作"所有国奖论文都如此"的断言——它是操作代理，不是评委打分表。

## 1. 角色链：先派角色，再对题号

**什么时候用**：题面有 2 问以上，且你正准备按 Q1/Q2/Q3 顺序写。

**怎么判定**：给每问指派 `first / main / extend / final` 之一，指派规则是硬的：

| 子问数 | 角色映射 |
|---|---|
| 1 | 该问同时是 main 与 final |
| 2 | first、final |
| 3 | first、main、final（稳健性并进 main 的验证或 final 的灵敏度） |
| ≥4 | first、main、一个或多个 extend、final |

- `first` 的判据：第一天能产出一个数、一张表或一条基线，且它给后面当尺子。
- `main` 的判据：换掉这个模型，题目要的交付物就变了。
- `extend` 的判据：它检验的是主模型**最强的那条假设**，不是随便加个指标。
- `final` 的判据：结论能写成建议/规则/阈值/方案，且每条都能追到前面某个数。

**反例**：四问写成四篇独立小论文，各用一套符号、各给一个结论，最后没有总决策。角色链断在 `final`。

## 2. 每问八格链：缺两格就退化成散文

**什么时候用**：任意一问动手写模型之前。

**怎么判定**：八格填满才允许开写——交付物、基线、升级、求解器、验证、图表、退路、依赖。缺 **基线** 或 **验证** 中任一格，判定为"散文段"，不是模型段。

**反例**：一上来 AHP+熵权+TOPSIS 三件套，没有等权基线、没有权重扰动下的秩稳定性。读者无法知道这套组合比"平均分"强在哪。

## 3. 题型模式库（按交付物选行，不按方法选行）

**什么时候用**：定完 `main` 的角色后，挑一条主路线。

| 题型 | 第一天的基线 | 一次针对性升级 | 判定用的测试 | 典型反例 |
|---|---|---|---|---|
| 机理/物理 | 量纲分析、守恒关系、单因素仿真 | 机理方程+标定，或有限差分 | 单位一致、极限情形、残差结构 | 方程漂亮但单位不齐、参数全靠猜 |
| 优化/调度 | 贪心、最短路、LP 松弛、现行策略 | MILP/网络流/动态规划/鲁棒优化 | 小例精确解间隙、约束满足、运行时间 | 元启发式无小例校验、目标与交付物不对应 |
| 预测/时序 | naive、季节 naive、移动平均、指数平滑 | ARIMA/状态空间/带领域特征的 ML | 滚动起点验证、残差自相关、区间覆盖 | 只报准确率，不说预测误差如何改变决策 |
| 评价/排序 | 归一化指标表、等权、Pareto 支配 | 熵权/AHP/TOPSIS（指标先立得住） | 权重扰动下秩相关、指标消融、已知例 | 指标堆砌，权重随意，排名不稳 |
| 网络/复杂系统 | 度、最短路、连通性、简单传播 | 加权/多层网络、流感知中心性、干预仿真 | 拓扑 vs 流感知结果差异、节点移除压力 | 因为"看起来现代"才建网络 |
| 仿真/博弈 | 收益矩阵、排队模型、小规模确定场景 | 多主体仿真、演化博弈、蒙特卡洛 | 规则可标定、小例可复现、参数敏感性 | 规则凭空发明，无极限情形对照 |
| 图像/信号/挖掘 | 阈值法、经典特征、规则抽取、逻辑回归 | 树模型/SVM/CNN（须交叉验证） | 混淆矩阵、消融、误差向下游传播 | 把准确率当最终答案，题目要的是测量或决策 |
| 成分/百分比数据 | 原始百分比描述统计、原始 PCA | 对数比变换（CLR/ILR）、闭合和约束特征 | 原始 vs 对数比消融、风化校正前后对比 | 直接对原始百分比跑 PCA/K-means，把闭合伪影当结构 |
| 纯方位/几何定位 | 正余弦定理三角化、普通最小二乘 | 可辨识性与最少源数证明、稳健非线性最小二乘 | 已知点反算、镜像解排除、蒙特卡洛角度噪声带 | 给一个三角公式加一次仿真，不证唯一性 |

**判定通则**：一张表里选不出一行，说明交付物还没定义清楚，先回 stage 2。

## 4. 反驳式选型：路线必须先被"打"过

**什么时候用**：任何候选路线准备定为主路线之前。

**怎么判定**：按顺序回答六问，答不上就降级——① 这个模型主张了什么？② 更简单的模型能不能也回答？③ 什么证据会让简单模型不够用？④ 什么条件会让选定模型失效？⑤ 哪个测试能分出高下？⑥ 失败后退到哪、还剩下什么完整的纸？

再填一张选型对阵表（基线 / 备选一 / 备选二 / 选定），每行必须有"它答什么、为何可能够用、为何可能崩、用哪个测试裁决、结论"。

**硬线**：**主路线在没被基线或某个备选按具名测试打败之前，不许定案。**

**`flip_condition` 必须可测**，可用的写法只有这几类：

- 时间型："若第一天 18:00 前基线产不出要求的交付物，换题。"
- 资源型："若全量 MILP 单次求解超 10 分钟，切贪心+局部搜索。"
- 稳定性型："若权重扰动下 Kendall τ 低于 0.7，改报分层而非精确排名。"
- 增益型："若交叉验证相对逻辑回归提升不足 3 个百分点，用可解释基线。"
- 分辨率型："若蒙特卡洛误差带覆盖全部备选方案，选更简单的稳健方案。"

**反例**：写"如果结果不理想就换模型"。这句话不可测，等于没写；评审无法据此在任何时刻触发换路。

## 5. 风险分级与救援模板

**什么时候用**：路线里出现非线性优化、中等规模 MILP、蒙特卡洛、树模型/SVM、有限差分、深度学习、大规模无分解 MILP、多目标元启发式。

**怎么判定**：给路线打风险档——低（闭式、线性回归、小规模 LP/MILP、贪心、有依据的 TOPSIS）、中（非线性优化、中等 MILP、蒙特卡洛、随机森林、SVM）、高（自建深度网络、大规模无分解 MILP、复杂主体仿真、多参数元启发式、无可靠假设的因果推断）。**高风险必须同时给出退路与消融计划**，只给退路不给消融，按中风险处理。

救援写法统一为三件套：`trigger`（可测条件/截止时间）→ `action`（更简单但完整的替代）→ `deadline`（何时停止尝试强路线）。

**反例**：写"必要时采用简化模型"。没有触发条件，等于永远不触发。

## 6. 反同质化：八招里至少用一招，且要在图/表里看得见

基线先行 · 路线级消融（去掉"创新层"看什么变了）· 小例精确校验 · 决策后悔（把预测/评价误差折算成决策损失）· 秩稳定性 · 不确定带 · 极限情形 · 领域专用特征。

**怎么判定**：能在正文里指出"这一招体现在第几张图/哪张表"。指不出来，就是没做。

**反例**：以"用了更先进的模型"当差异点。先进不是差异，被否掉的更简单方案才是差异的来源。
